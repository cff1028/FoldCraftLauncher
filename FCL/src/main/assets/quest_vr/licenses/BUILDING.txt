FCL Quest VR — build and relink

Source: https://github.com/cff1028/FoldCraftLauncher
Release: 0.1.1; package com.questfcl.launcher; VersionCode 21.
Merged upstream FCL 1.3.4.5 (b08db5e96a57bc74ae536fee337b32aa9c9ea156).

VR uses LWJGL 3.4.1 for Minecraft 26.1 and later, and 3.3.3 for older versions.
Version-specific Android OpenXR/OpenGLES compatibility bindings and rebuild
instructions are documented in third-party/quest-vr/JAVA-BINDINGS.md.
Non-Quest devices default to ordinary mode. VR requires explicit opt-in in
launcher settings, with a warning on first launch and each opt-in activation.

Built-in MobileGlues runs directly for Minecraft 1.17 / 21w10a and later.
Older and unknown versions retain the fixed-function compatibility layer.
External renderer plugins retain their user-selected compatibility setting.
SDL EGL lookup preserves missing symbols and uses the renderer's actual EGL library.
Vivecraft downloads offer separate QuestCraft and cff1028 sources.

VR stereo synchronization is enabled by default for each VR instance.
The launcher applies FCL_VR_STEREO_SYNC at the next game launch. The OpenXR
adapter waits for preceding GPU commands before releasing each eye image.
Use the matching unmodified QuestCraft Vivecraft mod for the Minecraft version.

Use JDK 17, Android SDK 35, NDK 27.0.12077973, CMake 3.22.1 and the Gradle wrapper.
Set ANDROID_HOME or sdk.dir in local.properties, then:
  ./gradlew :FCL:checkstyle :FCL:assembleFordebug -Darch=arm64
This makes a debug-signed APK suitable for installing a modified build.

For a release signed with your own key, set these environment variables:
  QUEST_FCL_KEYSTORE_FILE, QUEST_FCL_KEYSTORE_PASSWORD,
  QUEST_FCL_KEY_ALIAS, QUEST_FCL_KEY_PASSWORD
Then run:
  ./gradlew :FCL:assembleRelease -Darch=arm64
Keys are private and are not included in the repository or source archives.
An APK signed with a different key requires uninstalling the prior package
(back up game data first), or changing applicationId to install it separately.
CI build artifacts use a development key; releases use the existing Quest key.

MobileGlues: MobileGlues-2.0.1-Dev1-quest-source.zip includes the patched
source, dependencies and rebuild scripts. Follow mobileglues-fix/README-source.txt.
Replace FCL/src/main/jniLibs/arm64-v8a/libmobileglues.so with your rebuilt library.
The Quest compatibility patch preserves shader-source and procedure-lookup fixes,
and tracks uniform defaults with the compiled shader in its share group.
provenance.json records the input revisions, changed files and binary hash.

SimpleFPEWrapper: the release's SimpleFPEWrapper-3042d8a87b4d-source.zip includes
the exact revision identified by the bundled library's build stamp, dependencies
and original CMake/Gradle files. Build the SimpleFPEWrapper CMake shared target
with the NDK toolchain, ANDROID_ABI=arm64-v8a, ANDROID_PLATFORM=android-26,
ANDROID_STL=c++_static and CMAKE_BUILD_TYPE=Release. Replace
jni/arm64-v8a/libSimpleFPEWrapper.so inside FCL/libs/SimpleFPEWrapper-release.aar,
then rebuild the launcher. Source changes and toolchain paths can change hashes.

FCL's inherited dependencies and source projects remain credited in README;
their copyright notices and licenses continue to apply. For VR component
provenance and dependency licenses see third-party/quest-vr/README.md.
